# Miner History — Lyra

High-fidelity mock of the Miner History feature for Lyra (Phase 1).

## Run locally
Open `index.html` in a browser — no build step needed.

## Publish to GitHub Pages
1. Push the contents of this folder to the root of a GitHub repo (or `docs/` folder)
2. Repo Settings → Pages → Source: `main` branch, `/` root (or `/docs`)
3. Visit `https://<username>.github.io/<repo-name>/`
